# ToDo web application with API
A task management application built with React and TypeScript. It allows users to manage their daily tasks, track their progress, and organize todos by completion status.

The application integrates with the Mate Academy REST API to fetch and synchronize todo data.

## Features
- CRUD operations — create, edit, delete, and toggle todo completion status
- Dynamic filtering — filter tasks by All, Active, and Completed status
- API integration — fetch and synchronize todo data with the Mate Academy API
- Asynchronous UI states — loading indicators and temporary todo placeholders during API requests
- Form validation and error handling — handle invalid input and failed API requests
- Inline editing — edit todos directly in the list
- Keyboard interactions — use Enter to save and Escape to cancel editing
- Automatic input focus — focus the input field when creating or editing a todo

## Technologies

- React
- TypeScript
- React Hooks
- Bulma CSS Framework
- REST API
